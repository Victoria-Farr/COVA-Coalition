02 — Color-Coding System

Applied to the eight categories already in use on the events calendar. The two anchor colors carry COVA's own identity (its events, its top races); the new bold colors give the rest of the system genuine range and energy.

COVA Events Events run directly by COVA Coalition — the anchor mermaid blue
Key Race Event Tied to a high-priority race this cycle — the anchor lavender accent
Events Race-related, lower priority — outline treatment keeps it visually quieter
Key Issue Event Organized around a specific policy issue, not a candidate
Key Election Dates Voting deadlines, registration cutoffs, Election Day itself
Candidates A lighter tint of the lavender family — candidate-focused events not already covered by Key Race
Partner Organization Hosted by a coalition partner rather than COVA directly
Rapid Response Events Highest urgency — dark ground with hot magenta reads as "alert" without red
03 — Accessibility Standards

Every pairing checked against WCAG 2.1 — bold doesn't mean the accessibility discipline slips.

Contrast ratios (WCAG 2.1)
Mermaid Blue / White (COVA Events tag) — 4.72:1 — passes AA
Lavender / Ink Black (Key Race tag) — 7.53:1 — passes AAA
Electric Teal / Ink Black (Key Issue tag) — 9.92:1 — passes AAA
Vivid Amber / Ink Black (Election Dates tag) — 10.59:1 — passes AAA
Light Lavender Tint / Ink Black (School Board tag) — 14.63:1 — passes AAA
Ink Black / Hot Magenta (Rapid Response tag) — 4.17:1 — passes AA for large/bold tag text; the one pairing in this system worth using only at larger sizes, not small body copy
Accessibility / print-safe version — flat Ink Black on white or Warm Sand, no color dependency, for any asset that needs to survive a black-and-white printer or a low-vision reading context. Same principle as before: bold color for everyday use, a flat high-contrast version always available alongside it.
04 — Typography

Font Ninja identified Poppins on the live site — but comparing letterforms directly against the actual logo (the sharp apex on the "A," the open aperture on the "C") pointed to Jost SemiBold as the closer visual match for headline use. Inter stays as confirmed — it's already doing quiet duty on nav and blog body text — and becomes the consistent body copy everywhere, replacing Arial.

05 — Styling Notes

Small conventions that hold the whole system together visually.

Corner radius — 4px throughout. Applies to the palette swatches, the color-coding tags, and every card element (type-card, rotation-card, tag-row, asset-note). One consistent value, no exceptions — it's what keeps bold color blocks and quiet reference cards feeling like the same system.
